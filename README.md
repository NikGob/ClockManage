# ClockManage

Учебный режим для Windows: блокировка отвлекалок, таймер блоков с перерывами, журнал и локальный MCP для Claude.
Tauri 2 (Rust) + WebView, интерфейс в Material 3, живёт в трее.

## Установка

1. Скачай инсталлятор `ClockManage_*_x64-setup.exe` из артефактов GitHub Actions (вкладка **Actions → build → ClockManage-windows**) или из Releases.
2. Установи. Программа просит права администратора: без них не записать hosts и политики браузеров и не закрыть заблокированные приложения.
3. При первом запуске она сама создаёт две задачи в планировщике: запуск при входе в Windows (без окна UAC) и перезапуск раз в 5 минут, если процесс убили.

## Как устроен день

1. **План** — список блоков: «Математика 1,5 ч · Словацкий 1,5 ч · Экстернат 2,5 ч». Задаётся на экране «План» или через MCP.
2. **Начать день** — включает блокировку (в учебные дни из настроек) и первый отрезок.
3. Блок делится на отрезки по 45 мин с перерывом 10 мин. Между блоками перерыв 20 мин. Перерывы не съедают учебное время.
4. **Конец работы** → звук, уведомление, карточка «Перерыв» сверху экрана (не забирает фокус и клики).
5. **Конец перерыва** → будильник поверх экрана. Таймер **ждёт**, пока нажмёшь «Начать часть N». Блокировка при этом не снимается, звонок повторяется каждую минуту.
6. **Пауза** честно останавливает счёт — и работы, и перерыва. После паузы таймер сам не продолжает.
7. **Обед** — один раз за день, кнопкой в перерыве: без таймера (блок остаётся, потом «Пообедал») или таймер 45 мин с опцией «ем за ПК», которая открывает доступ на время обеда.
8. Блокировка снимается, когда отсижены все блоки, или в 22:00 МСК — что раньше.
9. Конец блока → уведомление «Надиктуй агенту строку: часы, что было скучно, куда отвлекался».

Есть режим **«Один таймер»**: без плана, работа + перерыв по кругу, блокировка по желанию.

## Блокировка

| Что | Как |
|---|---|
| Домены (`x.com`, `twitch.tv`, `web.telegram.org`…) | секция в `hosts` + политики `URLBlocklist` браузеров |
| Пути (`youtube.com/shorts`) | только политики браузеров — обычный YouTube остаётся доступен |
| Приложения (`Telegram.exe`, `Discord.exe`…) | watchdog закрывает процесс в течение секунды |

Поддержаны Chrome, Edge, Brave, Яндекс (политики применяются сразу) и Firefox (после перезапуска браузера).
Всё, что программа пишет в систему, записано в `blocker.json`, и при снятии блокировки удаляется только своё.
Если процесс убить, hosts и политики остаются в силе, а планировщик поднимает программу обратно.

Во время учебного дня список можно только **расширять**, план — только **добавлять и удлинять**.
Выход из трея тоже недоступен, пока идёт учёба.

### Доступ на паузе
Настройка «пускать в заблокированное на паузе» меняется **только после 22:00**. Если она включена, пауза даёт 10 минут доступа, потом блок возвращается, даже если пауза продолжается. Продлить можно через мини-капчу: три примера в уме, 15 секунд ожидания и удержание кнопки 3 секунды. Каждое продление пишется в лог.

### Аварийный доступ
Длинную фразу нужно переписать руками (вставка отключена). После этого доступ открывается на 10 минут, потом блокировка возвращается. Каждый случай пишется в лог.

### Известные ограничения
- Shorts, открытый кликом внутри YouTube, может показаться без перезагрузки страницы: сайт меняет URL без навигации. Политика сработает на следующем переходе или обновлении. Закрыть это на 100% можно только расширением браузера.
- Пользователь с правами администратора технически может всё откатить руками. Цель программы — создать трение, а не сделать это невозможным.

## Журнал

Каждый день хранится в `%APPDATA%\com.nikgob.clockmanage\days\YYYY-MM-DD.json`: фактическое время по блокам, паузы (сколько и сколько длились, был ли доступ), продления, аварийные доступы, обед, закрытые приложения.
Экспорт в JSON/CSV — кнопками на экране «Журнал» (файлы попадают в `Документы\ClockManage`).

## MCP для Claude

Порт выбирается случайно из диапазона 20000–64999 и сохраняется в конфиге. Сервер слушает только `127.0.0.1` и отклоняет запросы с чужими `Origin`/`Host`.
Точный адрес и готовая команда — в «Настройки → MCP для Claude»:

```sh
claude mcp add --transport http clockmanage http://127.0.0.1:<порт>/mcp
```

Инструменты:

| Инструмент | Что делает |
|---|---|
| `set_plan` | задать план дня: `{"blocks":[{"name":"Математика","hours":1.5},{"name":"Экстернат","minutes":150}], "save_as_template": false}` — во время блокировки только добавить/удлинить |
| `get_plan` | план на сегодня и шаблон |
| `get_session_state` | какой блок и часть, работа/перерыв/пауза/ожидание, сколько осталось, действует ли блокировка |
| `get_today_stats` | статистика дня (или `{"date":"2026-09-28"}`): план/факт по блокам, паузы, доступы, аварийные доступы, обед |

## Настройки

Всё редактируется в приложении, а также в `%APPDATA%\com.nikgob.clockmanage\config.json`:
учебные дни, конец дня, длительности отрезков и перерывов, блок-лист, доступ на паузе, фраза аварийного доступа, звук, будильник на экране, цвет (по умолчанию зелёный, схема строится по Material 3 из любого цвета), тема, MCP, автозапуск.

## Разработка

```sh
cargo test -p clockmanage-core              # логика таймера/блокировки/лога/MCP, работает на любой ОС
npx @tauri-apps/cli@2 dev                    # запуск на Windows (нужна консоль администратора)
npx @tauri-apps/cli@2 build                  # NSIS-инсталлятор
```

Превью интерфейса в обычном браузере с мок-бэкендом: `cd ui && python -m http.server`, затем
`index.html?state=work|paused|break|await|idle|done`, `overlay.html?demo=await|break|block|day|access`, `mini.html?state=work`.

Структура:

- `core/` — платформонезависимая логика: конфиг, движок дня (фазы, паузы, доступы), статистика и CSV, обработчик MCP. Покрыта тестами.
- `src-tauri/` — приложение: тикер, блокировщик Windows (hosts, реестр, процессы), синтез звуков, HTTP-сервер MCP, трей и окна.
- `ui/` — главное окно, мини-таймер и оверлей-будильник; чистый JS без сборщика; цветовая схема через `@material/material-color-utilities`.
